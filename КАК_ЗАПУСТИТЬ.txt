🐛 ПРОБЛЕМЫ И РЕШЕНИЯ
═══════════════════════════════════════════════════════════════

ПРОБЛЕМА: node-pty не устанавливается

Linux:
    sudo apt-get install build-essential python3
    npm rebuild node-pty

macOS:
    xcode-select --install
    npm rebuild node-pty

---

ПРОБЛЕМА: Порт 3001 занят

Решение:
    lsof -i :3001        # Найти процесс
    kill -9 <PID>        # Убить процесс
    
    # Или изменить порт
    echo "PORT=3002" >> .env

---

ПРОБЛЕМА: Backend не запускается

Решение:
    # Смотрите ошибки
    npm run dev:backend
    
    # Проверьте логи в консоли

---

ПРОБЛЕМА: AI не отвечает

Решение:
    1. Проверьте, что ваш AI API работает:
       curl http://localhost:8000/health
    
    2. Проверьте настройки в приложении
    
    3. Проверьте API ключ
