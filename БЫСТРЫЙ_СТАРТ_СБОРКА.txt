═══════════════════════════════════════════════════════════════════════════
🎮 КАК ИСПОЛЬЗОВАТЬ ПОСЛЕ УСТАНОВКИ
═══════════════════════════════════════════════════════════════════════════

1. УСТАНОВКА
   - Запустите .exe файл
   - Выберите папку (или оставьте по умолчанию)
   - Дождитесь завершения

2. ПЕРВЫЙ ЗАПУСК
   - Ярлык на рабочем столе: "AI Terminal IDE"
   - Или через меню Пуск
   
3. НАСТРОЙКА
   - Нажмите [⚙️ Settings]
   - Укажите:
     * Project Path: путь к вашему проекту
     * AI API URL: http://localhost:8000 (ваш AI API)
     * API Key: ваш ключ
     * Model: gpt-3.5-turbo
   - Нажмите Save

4. ИСПОЛЬЗОВАНИЕ
   - Слева: выберите файл в дереве
   - Центр: редактируйте код
   - Снизу: используйте терминал
   - Справа: задавайте вопросы AI

═══════════════════════════════════════════════════════════════════════════
🐛 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
═══════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА: node-pty не собирается

РЕШЕНИЕ:
    npm install --global windows-build-tools
    npm rebuild node-pty
    npm run build
    npm run package:win

─────────────────────────────────────────────────────────────────────────

ПРОБЛЕМА: Ошибка при сборке

РЕШЕНИЕ:
    rm -rf node_modules package-lock.json dist
    npm install
    npm run build
    npm run package:win

─────────────────────────────────────────────────────────────────────────

ПРОБЛЕМА: Установщик не запускается

РЕШЕНИЕ:
    - Проверьте antivirus (может блокировать)
    - Запустите от администратора
    - Проверьте место на диске (нужно ~500 MB)

─────────────────────────────────────────────────────────────────────────

ПРОБЛЕМА: Backend не стартует после установки

РЕШЕНИЕ:
    - Проверьте порт 3001 (должен быть свободен)
    - Запустите из командной строки для просмотра логов
    - Проверьте брандмауэр Windows

📊 ТЕХНИЧЕСКИЕ ДЕТАЛИ
═══════════════════════════════════════════════════════════════════════════

Что включено в установщик:

    ✓ Electron 28.1 (Desktop framework)
    ✓ Node.js runtime (встроенный)
    ✓ Express backend (порт 3001)
    ✓ Monaco Editor (code editing)
    ✓ xterm.js + node-pty (terminal)
    ✓ React 18.2 (UI)
    ✓ SQLite database (для истории)
    ✓ WebSocket server (для терминала и AI)
    ✓ Все node_modules

Размеры:

    Установщик:         ~150-200 MB
    После установки:    ~300-400 MB
    С данными:          ~350-450 MB

Системные требования:

    OS: Windows 10/11 (64-bit)
    RAM: 4 GB (рекомендуется 8 GB)
    Disk: 500 MB свободного места
    Port: 3001 (должен быть свободен)
