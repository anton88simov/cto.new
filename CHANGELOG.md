## [1.10] - Расширенная версия

### Добавлено
- **XAUUSD_PendingOrders_Advanced_EA.mq4** - расширенная версия с дополнительными функциями

- Организованные секции параметров для удобства настройки

- Совместимость с базовой версией (можно запускать параллельно)

## [1.00] - Первый релиз

### Добавлено базовых версий

#### XAUUSD_PendingOrders_EA.mq4
- Базовая версия для торговли отложенными ордерами
- Использование BuyStop и SellStop ордеров
- Автоматическое перевыставление ордеров через заданное время
- Обязательная установка Take Profit и Stop Loss
- Контроль спреда
- Защита от работы на неправильном таймфрейме/символе
- Расчет размера лота (фиксированный или процентный риск)
- Учет минимальных стоп-уровней брокера

#### XAUUSD_PendingLimit_EA.mq4
- Версия для торговли откатами
- Использование BuyLimit и SellLimit ордеров
- BuyLimit размещается ниже текущей цены (покупка на откате вниз)
- SellLimit размещается выше текущей цены (продажа на откате вверх)
- Все основные функции базовой версии
- Оптимизирована для флэтового рынка и коррекций

### Параметры

#### Основные
- `LotSize` - размер лота (по умолчанию 0.01)
- `TakeProfit` - тейк профит в пунктах (по умолчанию 100)
- `StopLoss` - стоп лосс в пунктах (по умолчанию 50)
- `PendingDistance` - дистанция для отложенного ордера (по умолчанию 30)
- `ReorderTime` - время до перевыставления в секундах (по умолчанию 300)
- `MagicNumber` - магический номер для идентификации (123456/123457)
- `TradeSymbol` - торговый символ (по умолчанию "XAUUSD")

#### Управление торговлей
- `UseBuyOrders` - использовать ордера на покупку (по умолчанию true)
- `UseSellOrders` - использовать ордера на продажу (по умолчанию true)
- `MaxSpread` - максимальный спред в пунктах (по умолчанию 50)
- `RiskPercent` - процент риска от депозита (по умолчанию 0)

### Функциональность

#### Управление ордерами
- Автоматическое размещение отложенных ордеров
- Мониторинг существующих ордеров
- Удаление старых ордеров по таймауту
- Перевыставление в новых актуальных местах
- Проверка на существование открытых позиций

#### Логика размещения
- **BuyStop**: выше максимума предыдущей свечи + дистанция
- **SellStop**: ниже минимума предыдущей свечи - дистанция
- **BuyLimit**: ниже минимума предыдущей свечи - дистанция
- **SellLimit**: выше максимума предыдущей свечи + дистанция

#### Расчеты
- Автоматический расчет размера лота на основе риска
- Нормализация цен в соответствии с Digits символа
- Учет минимальной дистанции для отложенных ордеров (StopLevel)
- Проверка минимального/максимального размера лота
- Округление лота до разрешенного шага (LotStep)

#### Безопасность
- Проверка таймфрейма (только M5)
- Проверка торгового символа
- Контроль спреда перед размещением ордеров
- Обязательное использование SL и TP
- Обработка ошибок при размещении ордеров

### Технические детали

#### Используемые функции MT4
- `OrderSend()` - размещение ордеров
- `OrderSelect()` - выбор ордера для работы
- `OrderDelete()` - удаление отложенного ордера
- `OrderModify()` - модификация ордеров (для трейлинга)
- `iHigh()`, `iLow()` - получение экстремумов свечей
- `iMA()` - Moving Average (расширенная версия)
- `iRSI()` - RSI индикатор (расширенная версия)
- `MarketInfo()` - получение информации о символе

#### Обработка ошибок
- `GetLastError()` - получение кода последней ошибки
- Логирование всех важных событий
- Информативные сообщения об ошибках
