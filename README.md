# Торговый советник XAUUSD Pending Orders EA для MetaTrader 4

## Описание
Это набор автоматических торговых советников (Expert Advisors) для MetaTrader 4, разработанных специально для торговли парой золото/доллар (XAUUSD) на таймфрейме M5 с использованием отложенных ордеров.

### Доступные версии:

1. **XAUUSD_PendingOrders_EA.mq4** - Базовая версия с BuyStop/SellStop ордерами
2. **XAUUSD_PendingOrders_Advanced_EA.mq4** - Расширенная версия с индикаторами и фильтрами
3. **XAUUSD_PendingLimit_EA.mq4** - Версия с BuyLimit/SellLimit для торговли откатами

## Основные возможности

### Ключевые функции:
- ✅ Торговля на паре XAUUSD (золото/доллар)
- ✅ Работа на таймфрейме M5
- ✅ Использование отложенных ордеров (BuyStop и SellStop)
- ✅ Обязательная установка Take Profit (TP) и Stop Loss (SL)
- ✅ Автоматическое перевыставление ордеров при неисполнении
- ✅ Контроль спреда
- ✅ Гибкие настройки параметров

## Принцип работы

### Логика торговли:
1. **Размещение отложенных ордеров**: EA размещает отложенные ордера BuyStop (выше текущей цены) и SellStop (ниже текущей цены)
2. **Мониторинг ордеров**: Советник постоянно отслеживает состояние отложенных ордеров
3. **Перевыставление**: Если цена не доходит до отложенного ордера в течение заданного времени (ReorderTime), ордер автоматически удаляется и создается новый в актуальном месте
4. **Управление рисками**: Каждый ордер имеет обязательный Stop Loss и Take Profit

### Размещение ордеров:
- **BuyStop**: Размещается выше максимума предыдущей свечи + дистанция
- **SellStop**: Размещается ниже минимума предыдущей свечи - дистанция

## Установка

1. Скопируйте нужный файл .mq4 в папку `MQL4/Experts` вашего терминала MetaTrader 4
   - Обычный путь: `C:\Program Files\MetaTrader 4\MQL4\Experts\`
   - Или через меню MT4: `Файл → Открыть каталог данных → MQL4 → Experts`

2. Перезапустите MetaTrader 4 или нажмите "Обновить" в навигаторе

3. Скомпилируйте советник:
   - Откройте MetaEditor (F4 в MT4)
   - Откройте нужный файл .mq4
   - Нажмите "Compile" (F7)

4. Перетащите советник на график XAUUSD M5

## Настройки параметров

### Основные параметры:

| Параметр | Описание | Рекомендуемое значение |
|----------|----------|------------------------|
| **LotSize** | Фиксированный размер лота | 0.01 |
| **TakeProfit** | Take Profit в пунктах | 100 |
| **StopLoss** | Stop Loss в пунктах | 50 |
| **PendingDistance** | Дистанция для отложенного ордера от уровня | 30 |
| **ReorderTime** | Время (в секундах) до перевыставления ордера | 300 (5 минут) |
| **MagicNumber** | Уникальный идентификатор ордеров | 123456 |
| **TradeSymbol** | Торговый символ | XAUUSD |
| **UseBuyOrders** | Включить ордера на покупку | true |
| **UseSellOrders** | Включить ордера на продажу | true |
| **MaxSpread** | Максимальный допустимый спред в пунктах | 50 |
| **RiskPercent** | Процент риска от депозита (0 = фикс. лот) | 0 |

### Дополнительные параметры расширенной версии:

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| **UseMAFilter** | Использовать фильтр Moving Average | false |
| **MA_Period** | Период MA | 50 |
| **MA_Method** | Метод MA (EMA, SMA и т.д.) | EMA |
| **UseRSIFilter** | Использовать фильтр RSI | false |
| **RSI_Period** | Период RSI | 14 |
| **RSI_BuyLevel** | RSI уровень для покупки | 30 |
| **RSI_SellLevel** | RSI уровень для продажи | 70 |
| **UseTimeFilter** | Использовать временной фильтр | false |
| **StartHour** | Час начала торговли | 8 |
| **EndHour** | Час окончания торговли | 20 |
| **UseTrailingStop** | Использовать трейлинг-стоп | false |
| **TrailingStop** | Размер трейлинг-стопа | 30 |
| **TrailingStep** | Шаг трейлинг-стопа | 10 |
| **MaxOrders** | Максимум ордеров на направление | 1 |

## Важные замечания

### ⚠️ Предупреждения:
1. **Таймфрейм**: Советник работает ТОЛЬКО на M5. При попытке запуска на другом таймфрейме будет выдана ошибка
2. **Символ**: Советник настроен на XAUUSD. Убедитесь, что используете правильное название символа у вашего брокера (может быть GOLD, XAUUSD, GOLDus и т.д.)
3. **Спред**: При высоком спреде торговля приостанавливается автоматически
4. **Стоп-уровни**: Советник автоматически учитывает минимальные стоп-уровни брокера

### 📊 Мониторинг:
- Проверяйте журнал (вкладка "Журнал" в MT4) для информации о размещении и удалении ордеров
- Следите за открытыми позициями и отложенными ордерами во вкладке "Торговля"
- При срабатывании отложенного ордера, новый ордер будет выставлен только после закрытия позиции

## Механизм перевыставления ордеров

Советник проверяет время жизни каждого отложенного ордера:
- Если ордер не исполнен в течение времени `ReorderTime` секунд
- Ордер автоматически удаляется
- На его место выставляется новый ордер с актуальными уровнями
- Новые уровни рассчитываются на основе текущей рыночной ситуации

Это обеспечивает:
- Актуальность торговых уровней
- Адаптацию к рыночным условиям
- Отсутствие "мертвых" ордеров

## Управление рисками

### Фиксированный лот:
```
LotSize = 0.01
RiskPercent = 0
```

### Процентный риск:
```
RiskPercent = 1.0  // 1% от депозита на сделку
```
При включении процентного риска, размер лота автоматически рассчитывается на основе:
- Баланса счета
- Размера Stop Loss
- Процента риска
