## 🚀 Как собрать .exe установщик

### Способ 1: Автоматический (самый простой)

```bash
./build-installer.sh
```

Скрипт все сделает сам и покажет меню выбора платформы.

### Способ 2: Вручную (2 команды)

```bash
# 1. Собрать все компоненты
npm run build

# 2. Создать установщик
npm run package:win
```

### Способ 3: Полный процесс

```bash
# 1. Установить зависимости (если не делали)
npm install

# 2. Собрать backend
npm run build:backend

# 3. Собрать frontend
npm run build:frontend

# 4. Собрать electron
npm run build:electron

# 5. Создать установщик
npm run package:win
```

## 🎮 Как работает готовое приложение

### При установке:
1. Пользователь запускает .exe
2. Выбирает папку (или оставляет `C:\Program Files\AI Terminal IDE`)
3. Приложение устанавливается
4. Создаются ярлыки (рабочий стол + меню Пуск)

### При запуске:
1. Electron стартует главное окно
2. Backend автоматически запускается на порту 3001
3. Через 2 секунды загружается UI
4. Пользователь видит полноценную IDE

## ⚙️ Настройки установщика

В `package.json` уже настроено:

```json
{
  "build": {
    "appId": "com.aiterminalide.app",
    "productName": "AI Terminal IDE",
    "win": {
      "target": ["nsis"]
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true,
      "createDesktopShortcut": true,
      "createStartMenuShortcut": true
    }
  }
}
```

Это означает:
- ✅ Пользователь может выбрать папку установки
- ✅ Создается ярлык на рабочем столе
- ✅ Добавляется в меню Пуск
- ✅ Можно удалить через "Программы и компоненты"

## 🐛 Решение проблем при сборке

### node-pty не собирается

**Windows:**
```bash
npm install --global windows-build-tools
npm rebuild node-pty
npm run build
npm run package:win
```

**Linux:**
```bash
sudo apt-get install build-essential python3
npm rebuild node-pty
npm run build
npm run package:linux
```

### better-sqlite3 ошибка

```bash
npm rebuild better-sqlite3
npm run build
npm run package:win
```

### Общие ошибки сборки

```bash
# Полная переустановка
rm -rf node_modules package-lock.json dist release
npm install
npm run build
npm run package:win
```
