# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### ❓ Какую версию EA выбрать?

**Для начинающих:**
- Начните с `XAUUSD_PendingOrders_EA.mq4` - базовая версия с простыми настройками

**Для опытных трейдеров:**
- Используйте `XAUUSD_PendingOrders_Advanced_EA.mq4` - с фильтрами и трейлинг-стопом

**Для торговли откатами:**
- Выбирайте `XAUUSD_PendingLimit_EA.mq4` - Limit ордера для коррекций

---

### ❓ Какой минимальный депозит нужен?

| Размер лота | Минимальный депозит | Рекомендуемый депозит |
|-------------|---------------------|----------------------|
| 0.01 | $100 | $200-300 |
| 0.05 | $500 | $800-1000 |
| 0.10 | $1000 | $1500-2000 |

⚠️ Это для консервативной торговли. Чем больше депозит, тем безопаснее.

---

### ❓ Почему EA работает только на M5?

EA специально настроен для 5-минутного таймфрейма, так как:
- Оптимальный баланс между частотой сигналов и качеством
- Достаточно времени для анализа и перевыставления ордеров
- Меньше рыночного шума, чем на M1
- Быстрее реакция, чем на M15 или выше

**Можно ли изменить?** Да, откройте код и измените проверку:
```mql4
if(Period() != PERIOD_M5)
```
Но это потребует перенастройки всех параметров!

---

### ❓ Мой брокер использует GOLD вместо XAUUSD, что делать?

Откройте файл .mq4 в MetaEditor и измените строку:
```mql4
input string TradeSymbol = "XAUUSD";
```
на
```mql4
input string TradeSymbol = "GOLD";
```

Или просто измените параметр `TradeSymbol` при запуске EA на графике.

## Проблемы и решения

### ❗ EA не размещает ордера

**Причины и решения:**

1. **Слишком большой спред**
   - Проверьте параметр `MaxSpread`
   - Увеличьте значение или торгуйте в другое время

2. **Недостаточная дистанция до ордера**
   - Увеличьте `PendingDistance`
   - У некоторых брокеров минимальная дистанция для отложенных ордеров 20-30 пунктов

3. **Не разрешена автоматическая торговля**
   - В MT4: Сервис → Настройки → Советники → Разрешить автоматическую торговлю
   - На графике должна быть "улыбающаяся" иконка EA (не грустная)

4. **Недостаточно средств**
   - Проверьте свободную маржу
   - Уменьшите размер лота

---

### ❗ Ордера постоянно удаляются и перевыставляются

Это нормальное поведение! EA перевыставляет ордера через `ReorderTime` секунд.

**Если это происходит слишком часто:**
- Увеличьте параметр `ReorderTime` (например, до 600 секунд = 10 минут)

**Если хотите, чтобы ордера жили дольше:**
```
ReorderTime = 900  // 15 минут
```

---

### ❗ EA размещает ордера, но они не срабатывают

**Причины:**

1. **Цена не доходит до уровня ордера**
   - Для BuyStop/SellStop: уменьшите `PendingDistance`
   - Для BuyLimit/SellLimit: увеличьте `PendingDistance`

2. **Ордер удаляется раньше, чем срабатывает**
   - Увеличьте `ReorderTime`
   - Уменьшите `PendingDistance`

3. **Слишком большой StopLevel брокера**
   - Проверьте минимальную дистанцию у вашего брокера
   - Выберите брокера с меньшими ограничениями

---

### ❗ Много убыточных сделок

**Рекомендации:**

1. **Используйте фильтры (расширенная версия):**
   ```
   UseMAFilter = true
   UseRSIFilter = true
   ```

2. **Торгуйте только в определенное время:**
   ```
   UseTimeFilter = true
   StartHour = 14  // Американская сессия
   EndHour = 20
   ```

3. **Увеличьте TakeProfit относительно StopLoss:**
   ```
   TakeProfit = 100
   StopLoss = 50
   // Соотношение 2:1
   ```

4. **Протестируйте на истории:**
   - Используйте тестер стратегий MT4
   - Оптимизируйте параметры
   - Тестируйте минимум на 3-6 месяцах данных

---

### ❗ EA не компилируется

**Ошибки компиляции:**

1. **"Undeclared identifier"** (необъявленный идентификатор)
   - Убедитесь, что скопировали весь код
   - Проверьте, что нет опечаток

2. **"Invalid character"** (неверный символ)
   - Возможно, проблема с кодировкой
   - Пересохраните файл в UTF-8

3. **Версия MetaTrader**
   - EA написан для MT4, не работает на MT5
   - Убедитесь, что используете MT4

## Настройка и оптимизация

### ❓ Как оптимизировать параметры?

**Шаг 1:** Откройте тестер стратегий (Ctrl+R)

**Шаг 2:** Выберите параметры для оптимизации:
- TakeProfit: от 50 до 200, шаг 25
- StopLoss: от 30 до 100, шаг 10
- PendingDistance: от 20 до 60, шаг 10

**Шаг 3:** Запустите оптимизацию на истории (минимум 3 месяца)

**Шаг 4:** Выберите результаты с:
- Profit Factor > 1.5
- Процент прибыльных сделок > 50%
- Максимальная просадка < 20%

**Шаг 5:** Протестируйте лучшие результаты на другом периоде (форвард-тест)

---

### ❓ Какие параметры самые важные?

**Топ-5 важных параметров:**

1. **StopLoss** - защищает от больших убытков
2. **TakeProfit** - определяет размер прибыли
3. **PendingDistance** - влияет на частоту срабатывания ордеров
4. **ReorderTime** - определяет, как часто обновляются ордера
5. **LotSize / RiskPercent** - управление размером позиции

**Начните с изменения этих параметров**, остальные - вторичные.

---

### ❓ Как включить трейлинг-стоп?

**Только в расширенной версии** (`XAUUSD_PendingOrders_Advanced_EA.mq4`):

```
UseTrailingStop = true
TrailingStop = 40     // Дистанция трейлинга в пунктах
TrailingStep = 10     // Минимальный шаг для перемещения SL
```

**Как это работает:**
- Когда сделка в прибыли > `TrailingStop` пунктов
- StopLoss автоматически подтягивается за ценой
- При движении минимум на `TrailingStep` пунктов

## Риск-менеджмент

### ❓ Фиксированный лот или процентный риск?

**Фиксированный лот:**
```
RiskPercent = 0
LotSize = 0.01
```
✅ Простой и понятный  
✅ Стабильный размер позиции  
❌ Не учитывает рост/падение депозита  

**Процентный риск:**
```
RiskPercent = 1.0
StopLoss = 50
```
✅ Адаптируется к размеру депозита  
✅ Защищает при просадке  
✅ Увеличивает позицию при росте  
❌ Более сложный расчет  

**Рекомендация:** Для начинающих - фиксированный лот, для опытных - процентный риск.

---

### ❓ Какой процент риска безопасен?

| Риск на сделку | Тип стратегии | Допустимая просадка |
|----------------|---------------|---------------------|
| 0.5% | Очень консервативный | 10-15% |
| 1.0% | Консервативный | 15-25% |
| 2.0% | Умеренный | 25-40% |
| 3.0% | Агрессивный | 40-60% |

⚠️ **Никогда не рискуйте более 5% на одну сделку!**

---

### ❓ Можно ли торговать на реальном счете сразу?

**НЕТ! Категорически не рекомендуется!**

**Правильная последовательность:**

1. **Тестирование на истории** (1-2 дня)
   - Используйте тестер стратегий MT4
   - Проверьте на разных периодах

2. **Демо-счет** (2-4 недели)
   - Реальные рыночные условия
   - Реальные спреды и проскальзывания
   - Проверьте стабильность

3. **Микро-реал** (1-2 месяца)
   - Минимальный депозит ($100)
   - Лот 0.01
   - Психологическая адаптация

4. **Полноценный реал**
   - После успешного тестирования
   - С уверенностью в стратегии

## Технические вопросы

### ❓ EA работает только когда MT4 включен?

**Да!** EA - это программа, которая запускается внутри MT4.

**Решения:**

1. **Оставьте компьютер включенным 24/7**
   - Не рекомендуется (высокое энергопотребление)

2. **Используйте VPS (Virtual Private Server)**
   - ✅ Работает 24/7
   - ✅ Быстрое подключение к серверу брокера
   - ✅ Надежность
   - Стоимость: $10-30/месяц

3. **VPS от брокера**
   - Многие брокеры предоставляют бесплатный VPS
   - Обычно требуется минимальный депозит или оборот

---

### ❓ Можно ли запустить несколько EA одновременно?

**Да!** Но с разными `MagicNumber`:

**EA №1 (пробои):**
```
MagicNumber = 111111
```

**EA №2 (откаты):**
```
MagicNumber = 222222
```

**Важно:**
- Разные MagicNumber обязательны!
- Следите за общей нагрузкой на депозит
- Уменьшите размер лота для каждого EA

---

### ❓ EA работает на других парах?

EA оптимизирован для XAUUSD, но **теоретически** можно использовать на:
- GBPUSD
- EURUSD
- USDJPY

**Что нужно сделать:**
1. Изменить `TradeSymbol`
2. Перенастроить `TakeProfit`, `StopLoss`, `PendingDistance`
3. Протестировать на истории
4. Возможно, изменить `MaxSpread`

⚠️ **Не гарантируется, что EA будет прибыльным на других парах!**

---

### ❓ Как обновить EA на новую версию?

1. Закройте все позиции и отложенные ордера текущего EA
2. Удалите EA с графика
3. Скопируйте новый файл .mq4 в папку `MQL4/Experts`
4. Перезапустите MT4 или обновите в навигаторе
5. Перетащите новый EA на график
6. Настройте параметры

⚠️ **Лучше всего обновлять, когда нет открытых позиций!**

## Прибыльность

### ❓ Сколько можно заработать?

**Невозможно гарантировать прибыль!** Результаты зависят от:
- Рыночных условий
- Настроек EA
- Дисциплины (не вмешиваться в работу EA)
- Управления рисками

**Реалистичные ожидания:**
- Месячная доходность: 5-15% (хорошо)
- Месячная доходность: 20-30% (отлично, но риск выше)
- Месячная доходность: >50% (нереалистично на длительном периоде)

⚠️ **Любая торговля связана с риском убытков!**

---

### ❓ Были ли убыточные периоды?

**Да, это нормально!** Ни одна стратегия не дает 100% прибыльных сделок.

**Ожидаемая статистика:**
- Процент прибыльных сделок: 50-65%
- Просадка: 10-30%
- Profit Factor: 1.5-2.5

**Убыточные периоды происходят:**
- Во время низкой волатильности (флэт)
- При резких новостных движениях
- В периоды смены тренда

**Как минимизировать:**
- Используйте фильтры
- Торгуйте только в оптимальное время
- Следите за новостным календарем

## Безопасность

### ❓ Безопасно ли использовать EA?

**Да, если соблюдаете правила:**

✅ Всегда тестируйте на демо-счете  
✅ Начинайте с минимального лота  
✅ Используйте StopLoss  
✅ Не рискуйте больше, чем можете потерять  
✅ Регулярно проверяйте работу EA  

❌ Не оставляйте EA без присмотра на долгое время  
❌ Не используйте на реальном счете без тестирования  
❌ Не рискуйте последними деньгами  

---

### ❓ EA может обнулить депозит?

**Теоретически - да**, если:
- Используете слишком большой лот
- Торгуете без StopLoss (EA всегда использует SL!)
- Игнорируете риск-менеджмент
- Запускаете несколько EA с большими лотами

**Защита:**
- EA всегда устанавливает StopLoss
- Используйте разумный размер лота
- Максимальный риск 1-2% на сделку
- Следите за свободной маржой
