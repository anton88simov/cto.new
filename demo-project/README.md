# Demo Project

Это демонстрационный проект для тестирования AI Terminal IDE.

## Файлы

- `example.js` - Простой JavaScript файл с функциями
- `package.json` - Конфигурация проекта
- `README.md` - Этот файл

## Как использовать

1. Откройте AI Terminal IDE
2. В Settings укажите путь к этой папке
3. Откройте `example.js` в редакторе
4. Попробуйте задать AI вопросы:

### Примеры вопросов для AI:

**Генерация тестов:**
```
Напиши Jest тесты для функций calculateSum и findMax
```

**Добавление функционала:**
```
Добавь в класс UserManager метод removeUser(id)
```

**Рефакторинг:**
```
Переписать класс UserManager с использованием TypeScript
```

**Документация:**
```
Добавь JSDoc комментарии ко всем функциям
```

**Исправление кода:**
```
Найди потенциальные проблемы в этом коде
```

## Terminal команды

Попробуйте в терминале:

```bash
# Показать содержимое
ls -la

# Создать новый файл
touch test.js

# Посмотреть содержимое файла
cat example.js

# Создать npm проект
npm init -y

# Установить зависимости
npm install lodash
```
