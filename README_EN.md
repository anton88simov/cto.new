# XAUUSD Pending Orders EA for MetaTrader 4

## Description
Automated trading advisors (Expert Advisors) for MetaTrader 4, specifically designed for trading Gold/USD (XAUUSD) on M5 timeframe using pending orders.

## Features
✅ Automated pending orders (Stop/Limit)  
✅ Auto re-ordering when orders not triggered  
✅ Mandatory Take Profit and Stop Loss  
✅ Risk management (fixed lot or percentage)  
✅ Spread control  
✅ Technical indicators filters (Advanced version)  
✅ Trailing stop (Advanced version)  

## Available Versions

### 1. Base Version (XAUUSD_PendingOrders_EA.mq4)
Simple BuyStop/SellStop strategy for breakout trading

### 2. Advanced Version (XAUUSD_PendingOrders_Advanced_EA.mq4)
Enhanced version with MA/RSI filters, trailing stop, time filters

### 3. Limit Version (XAUUSD_PendingLimit_EA.mq4)
BuyLimit/SellLimit strategy for pullback trading

## Quick Start

1. Copy `.mq4` file to `MetaTrader 4/MQL4/Experts/`
2. Compile in MetaEditor (F7)
3. Drag EA to XAUUSD M5 chart
4. Configure parameters
5. Enable auto-trading
