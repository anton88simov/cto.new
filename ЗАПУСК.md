# Инструкция по запуску AI Terminal IDE

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Проверка установки

```bash
./test-setup.sh
```

Все должно быть ✓ (зеленая галочка).

### 3. Запуск приложения

**Вариант A: Полное приложение (рекомендуется)**

```bash
npm run dev
```

Откроется Electron приложение с:
- Редактором кода (Monaco Editor)
- Терминалом (снизу)
- AI панелью (справа)
- Деревом файлов (слева)

**Вариант B: Только в браузере (для разработки)**

Терминал 1 - Backend:
```bash
npm run dev:backend
```

Терминал 2 - Frontend:
```bash
npm run dev:frontend
```

Откройте в браузере: http://localhost:5173

### 4. Первоначальная настройка

После запуска:

1. Нажмите **⚙️ Settings**
2. Заполните:
   - **Project Path**: `/путь/к/вашему/проекту`
   - **AI API URL**: `http://localhost:8000` (или URL вашего AI API)
   - **API Key**: ваш ключ от AI API
   - **Default Model**: `gpt-3.5-turbo`
3. Нажмите **Save**

## 🐛 Решение проблем

### Ошибка при npm install

**Linux:**
```bash
sudo apt-get install build-essential python3
npm install
```

**macOS:**
```bash
xcode-select --install
npm install
```

### Порт 3001 занят

```bash
# Найти процесс
lsof -i :3001

# Убить процесс
kill -9 <PID>

# Или изменить порт в .env
echo "PORT=3002" >> .env
```

### Backend не запускается

Проверьте логи:
```bash
npm run dev:backend
```

Смотрите ошибки в консоли.

### Терминал не подключается

1. Убедитесь, что backend работает
2. Проверьте WebSocket в консоли браузера (F12)
3. Перезапустите приложение

### AI не отвечает

1. Проверьте настройки (Settings)
2. Убедитесь, что ваш AI API работает:
   ```bash
   curl http://localhost:8000/health
   ```
3. Проверьте API ключ


## 🎯 Основные команды

```bash
# Разработка
npm run dev              # Запустить все
npm run dev:backend      # Только backend
npm run dev:frontend     # Только frontend

# Сборка
npm run build            # Собрать все
npm run build:backend    # Только backend
npm run build:frontend   # Только frontend

# Production
npm start                # Запустить собранное приложение

# Утилиты
npm run lint             # Проверка кода
npm run format           # Форматирование
./test-setup.sh          # Проверка установки
./test-backend.sh        # Тест backend
```

## 💡 Подсказки

1. **Для начала** откройте любой ваш проект через Settings → Project Path
2. **Используйте AI** для генерации кода, рефакторинга, поиска багов
3. **Терминал** полностью функциональный - можете запускать любые команды
4. **История AI** сохраняется в SQLite базе в папке `data/`
5. **Безопасность** - опасные команды (rm -rf) требуют подтверждения

## 🔐 Безопасность

- API ключи хранятся локально и не передаются никуда
- Опасные команды валидируются перед выполнением
- Секреты фильтруются из вывода терминала
- Все данные хранятся только локально
